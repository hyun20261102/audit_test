법인카드 사용내역

엑셀(.xlsx/.xls) 또는 CSV. 헤더 행에 순번, 카드번호, 이용자명, 이용일, 가맹점명, 이용금액, 가맹점 주소 … 컬럼이 있어야 합니다. 여러 파일을 올리면 합쳐집니다(승인번호 기준 중복 제거).

직원 집주소

이용자명과 집주소를 등록합니다. 동명이인은 카드번호 뒤 4자리로 구분하세요. 엑셀 업로드(컬럼: 이용자명, 집주소, 카드끝4자리(선택)) 또는 직접 입력.

생성한 보고서는 이 브라우저에 최근 30건까지 자동 보관됩니다.

상단 기간·반경 필터가 적용된 분석 결과(집계 수치와 주요 의심 거래 최대 60건)를 Gemini로 전송합니다. 집주소·카드번호는 전송하지 않으며, 가명 처리 시 이름은 '직원01' 형태로 보내고 응답을 받은 뒤 화면에서 실명으로 되돌립니다.

AI가 작성한 초안입니다. 수치는 하단 부록(시스템 산출값)과 대조 후 사용하세요.
버튼을 누르면 이곳에 결과가 표시됩니다.

카카오 지도 API

카카오 디벨로퍼스 > 내 애플리케이션 > 플랫폼 > Web 사이트 도메인에 를 등록하고, 카카오맵 사용 설정을 ON 해야 합니다.

Gemini API (AI 보고서)

키는 https://aistudio.google.com 에서 발급합니다. 이 브라우저에만 저장되며, 보고서 생성 시 Google 서버로 직접 전송됩니다.

분석 기준

① 집근처 사용 = 집 반경 내 오프라인 가맹점 사용 (온라인·PG 결제 제외)
② 휴일 사용 = 토·일·공휴일 사용 (위치 무관, 온라인 포함)
③ 심야 사용 = 심야 시간대 승인 (위치 무관, 온라인 포함)
점검대상(복합) = ① 이면서 (휴일 / 심야 / 주의 업종) 중 하나 이상 · 취소전표는 모두 제외
