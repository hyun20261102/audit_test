# 법인카드 집근처 사용 분석

법인카드 사용내역(엑셀/CSV)과 직원 집주소를 카카오 지도로 좌표 변환해, 집 반경 내 사용·주말/공휴일·심야·주의업종 사용을 찾아내는 웹 도구입니다.
모든 데이터는 **브라우저(localStorage)에만 저장**되며 서버로 전송되지 않습니다. 주소 → 좌표 변환 시 주소 문자열만 카카오 API로 전송됩니다.

## 실행
1. `실행.bat` 더블클릭 → `http://localhost:8080` 이 열립니다. (창을 닫으면 서버 종료)
2. 카카오 디벨로퍼스(https://developers.kakao.com) 에서
   - 애플리케이션 생성 → **앱 키 > JavaScript 키** 복사
   - **플랫폼 > Web 사이트 도메인**에 `http://localhost:8080` 등록
   - **카카오맵 사용 설정 ON**
3. 앱의 **설정** 탭에 JavaScript 키 입력 → 저장 및 연결

## 사용 순서
1. **데이터 등록**: 사용내역 업로드(여러 파일 가능, 중복 자동 제외) → 집주소 입력(엑셀 양식 다운로드/업로드 가능, 동명이인은 카드끝4자리)
2. **좌표 변환 + 분석 실행**
3. **대시보드**: 직원별 집근처 건수·금액·비중, 점검대상, 거리 구간별/업종별 금액
4. **지도 분석**: 집(초록)·반경 원, 점검대상(빨강)·집근처(주황)·기타(회색) 가맹점
5. **거래 내역**: 필터/검색 후 분석 컬럼을 붙여 엑셀 내보내기
6. **AI 보고서** (Gemini): `이상징후 요약`(감사 담당자용) / `경영진 보고서 생성`(개조식 공식 보고서)
   - 설정 탭에 Gemini API 키(https://aistudio.google.com 발급) 입력 → 저장 및 연결 테스트
     (그 키로 사용 가능한 모델 목록을 API에서 불러와 최신 flash 모델을 자동 선택. 모델이 단종되면 다시 누르면 됨)
   - 전송 데이터: 상단 기간·반경 필터 기준 집계 수치 + 주요 의심 거래 최대 60건. **집주소·카드번호는 전송하지 않음**
   - "직원 이름 가명 처리" 체크 시 이름을 `직원01` 형태로 보내고, 응답을 화면에서 실명으로 복원
   - 보고서 하단에 AI와 무관한 **시스템 산출 부록**(시나리오별·직원별 수치, 우선 확인 거래)이 붙음 → AI 수치와 대조
   - 복사(서식 포함) / Word(.doc) 저장 / 인쇄·PDF

## 판정 기준 (설정 탭에서 변경)
- **① 집근처 사용**: 가맹점 좌표가 집 좌표에서 반경(기본 1km) 이내 (오프라인 가맹점만)
- **② 휴일 사용**: 토·일·공휴일 사용 (위치 무관, 온라인/PG 결제 포함)
- **③ 심야 사용**: 심야 시간대(기본 22:00~06:00) 승인 (위치 무관, 온라인/PG 결제 포함)
- **점검대상(복합)**: ① 이면서 휴일 / 심야 / 주의업종 중 하나 이상
- 취소전표는 모든 시나리오에서 제외
- **분석 제외**: 취소전표, PG 하위가맹점(가맹점명에 ` - ` 포함, 예: `카카오 - 주식회사 카카오`), 제외 키워드(PG·온라인 등)
  → 이런 거래의 주소는 PG사 본사 주소이므로 실제 사용 위치가 아닙니다.
- 주소 변환은 원문 → 도로명+건물번호 → 지번 → 상호명 검색 순서로 시도합니다(결과의 `좌표변환결과` 컬럼에 표시).
- 공휴일은 2025~2026년 기본값이 들어 있으니 연도가 바뀌면 설정에서 추가하세요.
- 존재하지 않는 날짜(예: `2026.02.29`)는 `날짜오류`로 표시되고 기간 필터와 무관하게 항상 포함됩니다.

## 파일 구성

- `serve.ps1` 로컬 웹서버(PowerShell, 별도 설치 불필요)
